# IkBenMedia — Intelligent Ontwerp

Website van IkBenMedia, de ontwerpstudio van Ischa Biesbrouck (Haarlem).

Statische site zonder build-stap: `index.html`, `assets/css/style.css`, `assets/js/main.js`.
Gehost via GitHub Pages (branch `main`, map `/`).

Lokaal bekijken:

```bash
python -m http.server 8800
```

Het contactformulier opent het e-mailprogramma van de bezoeker met een ingevuld bericht aan info@ikbenmedia.nl (GitHub Pages heeft geen server).
